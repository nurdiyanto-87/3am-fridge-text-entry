A smart fridge texts its owner at 3am: it's haunted — by the ghost of every snack promised for "tomorrow". And the ghost only eats the good ones. One line, 124 characters, pure Python standard library, no input, no network, deterministic.

## Run it

```sh
python3 main.py
```

Writes the single-line text to `/output/entry.txt` (1–140 characters, UTF-8, no trailing newline). Check it with:

```sh
python3 test_entry.py
```
